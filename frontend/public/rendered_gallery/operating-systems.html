Minix 3

2005

A highly reliable microkernel-based operating system designed for high availability and education. Unlike monolithic kernels where a single bug can crash the whole system, Minix 3 runs most system services (like drivers) as user-space processes that can be automatically restarted if they fail. It famously served as the inspiration for Linus Torvalds when he began writing Linux.

Based on: Independent
Kernel: Microkernel
Pkg Manager: Pkgin
UI / Desktop: Shell / X11
Key Highlights:

  • Tiny kernel footprint
  • POSIX compliant
  • Inspiration for Linux (historically)

Alpine Linux

2005

A security-oriented, lightweight Linux distribution that has become the de facto standard for Docker containers. By using musl libc and busybox instead of the larger GNU tools, Alpine achieves an incredibly small footprint (~5MB for a base image). Its small size and focus on security (with stack smashing protection by default) make it ideal for modern, cloud-native deployments.

Based on: Independent
Kernel: Linux (PaX patched)
Pkg Manager: APK
UI / Desktop: None (headless)
Key Highlights:
  • Extremely small footprint (~5MB)
  • Security-oriented (stack smashing protection)
  • Uses musl libc instead of glibc
  • Simple and functional
