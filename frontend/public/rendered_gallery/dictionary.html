Abandonware

A Software

Product, typically software, that is no longer supported or marketed by its creator. It may still be available but is often in a legal grey area regarding copyright.

Keywords
Use Cases
  • Retro gaming
  • Archiving old software
Did you know?
  • Often kept alive by community enthusiasts.

Accuracy

A Metric

A metric measuring the proportion of correct predictions (both true positives and true negatives) among the total number of cases examined.

Keywords
Use Cases
  • General model evaluation
Did you know?
  • Can be misleading on imbalanced datasets.

ACID

A Database

Atomicity, Consistency, Isolation, Durability. A set of properties of database transactions intended to guarantee data validity despite errors, power failures, and other mishaps.

Keywords
Use Cases
  • Financial transactions
  • Critical data storage
Did you know?
  • Relational databases (SQL) typically prioritize ACID.

Agent Driven Development

A AI

A software development methodology where AI agents are used to autonomously or semi-autonomously write, test, and deploy code, often under human supervision.

Keywords
Use Cases
  • Rapid prototyping
  • Code refactoring
  • Automated testing
Did you know?
  • Shifts the developer role from writer to reviewer and architect.

API Gateway

A Microservices

An API management tool that sits between a client and a collection of backend services. It acts as a reverse proxy to accept all application programming interface (API) calls, aggregate the various services required to fulfill them, and return the appropriate result.

Keywords
Use Cases
  • Rate limiting
  • Authentication/Authorization
  • Request routing
Did you know?
  • Simplifies the client interface for microservices.

Async

A Asynchronous

Short for 'asynchronous', it refers to a programming pattern where operations can occur independently of the main program flow. In JavaScript, the `async` keyword declares a function that implicitly returns a Promise.

Keywords
Use Cases
  • Fetching data from an API without freezing the UI
  • Reading files from disk
  • Timer-based operations
Did you know?
  • Introduced in ES2017 (ES8).
  • Async functions always return a promise.

AUC

A Metric

Area Under (the ROC) Curve. A single scalar value that aggregates the performance of a classifier across all possible classification thresholds.

Keywords
Use Cases
  • Evaluating binary classifiers
  • Model selection
Did you know?
  • AUC of 0.5 represents a random guess; 1.0 is perfect classification.

Avro

A Big Data

A row-based data serialization system that relies on schemas. It is best suited for write-heavy operations and data serialization where schema evolution is expected.

Keywords
Use Cases
  • Kafka message payloads
  • Data serialization for RPC
Did you know?
  • Avro schemas are defined in JSON.

Await

A Promise

An operator used inside an `async` function to pause execution until a Promise is resolved or rejected. It makes asynchronous code look and behave like synchronous code.

Keywords
Use Cases
  • Waiting for a database query to finish
  • Sequential API calls where one depends on the other
Did you know?
  • Can only be used inside async functions (or top-level await in modules).
  • If the promise rejects, it throws an error.

B-Tree

B Database

A self-balancing tree data structure that maintains sorted data and allows searches, sequential access, insertions, and deletions in logarithmic time.

Keywords
Use Cases
  • Standard database indexes (MySQL, PostgreSQL)
Did you know?
  • Optimized for systems that read and write large blocks of data.

Backfilling

B Data Engineering

The process of processing data that corresponds to a time period that has already passed. It is often used when a new metric is defined or a bug is fixed.

Keywords
Use Cases
  • Computing a new KPI for the past year
  • Recovering from a pipeline failure
Did you know?
  • Airflow has built-in support for backfilling.

Benchmarking

B Comparison

The practice of comparing business processes and performance metrics to industry bests and best practices from other companies.

Keywords
Use Cases
  • Computer Hardware testing
  • Business process improvement
Did you know?
  • Essential for understanding relative performance.

Bias-Variance Tradeoff

B Error

The property of a model that the variance of the parameter estimated across samples can be reduced by increasing the bias in the estimated parameters. The goal is to find a balance that minimizes total error.

Keywords
Use Cases
  • Tuning model complexity
Did you know?
  • High bias leads to underfitting; high variance leads to overfitting.

Big O Notation

B Complexity

A mathematical notation that describes the limiting behavior of a function when the argument tends towards a particular value or infinity. In CS, it's used to classify algorithms according to how their run time or space requirements grow as the input size grows.

Keywords
Use Cases
  • Analyzing algorithm efficiency
  • Interview questions
Did you know?
  • O(1) is constant time, O(n) is linear, O(n^2) is quadratic.

Binary Search

B Algorithm

A search algorithm that finds the position of a target value within a sorted array. It compares the target value to the middle element of the array.

Keywords
Use Cases
  • Searching in large sorted datasets
Did you know?
  • Time complexity is O(log n).

Bloom Filter

B Probabilistic

A space-efficient probabilistic data structure that is used to test whether an element is a member of a set. False positive matches are possible, but false negatives are not.

Keywords
Use Cases
  • Checking if a URL is malicious
  • Avoiding disk lookups for non-existent keys
Did you know?
  • Very fast and memory efficient.

Boilerplate

B Code

Sections of code or text that are repeated in multiple places with little or no variation. In programming, it refers to standard code required to achieve a task properly.

Keywords
Use Cases
  • Setting up a server
  • Legal contracts
  • React component structure
Did you know?
  • Frameworks often aim to reduce boilerplate.

Broadcast Join

B Optimization

A join strategy in distributed systems where the smaller table is sent (broadcasted) to all worker nodes, avoiding a shuffle of the larger table.

Keywords
Use Cases
  • Joining a massive fact table with a small dimension table
Did you know?
  • Significantly faster than a shuffle join if one table fits in memory.

Caching

C Performance

The process of storing copies of files in a temporary storage location, or cache, so that they can be accessed more quickly.

Keywords
Use Cases
  • Browser cache
  • Redis/Memcached
  • CDN
Did you know?
  • Cache invalidation is one of the hardest things in CS.

Callback

C Higher-order function

A function passed as an argument to another function, which is then invoked inside the outer function to complete some kind of routine or action.

Keywords
Use Cases
  • Event handling (e.g., button click)
  • Array methods like .map() or .filter()
  • Asynchronous operations (legacy style)
Did you know?
  • Callbacks are the fundamental unit of asynchronous JS.
  • Can be synchronous or asynchronous.

Callback Hell

C Nesting

A situation where callbacks are nested within other callbacks several levels deep, making the code difficult to read, understand, and maintain. Also known as the 'Pyramid of Doom'.

Keywords
Use Cases
  • (Anti-pattern) Handling multiple sequential asynchronous operations without Promises
Did you know?
  • Promises and Async/Await were introduced largely to solve this problem.

CAP Theorem

C Distributed Systems

States that it is impossible for a distributed data store to simultaneously provide more than two out of the following three guarantees: Consistency, Availability, and Partition tolerance.

Keywords
Use Cases
  • Choosing a database (SQL vs NoSQL)
  • Designing distributed systems
Did you know?
  • You usually have to choose between CP (Consistency/Partition tolerance) or AP (Availability/Partition tolerance) in distributed systems.

CDC

C Replication

Change Data Capture. A set of software design patterns used to determine and track the data that has changed so that action can be taken using the changed data.

Keywords
Use Cases
  • Real-time database replication
  • Streaming database changes to Kafka
Did you know?
  • Debezium is a popular open-source CDC tool.

CDN

C Performance

Content Delivery Network. A geographically distributed network of proxy servers and their data centers. The goal is to provide high availability and performance by distributing the service spatially relative to end-users.

Keywords
Use Cases
  • Serving static assets (images, CSS, JS) quickly
  • Streaming video
Did you know?
  • Cloudflare and Akamai are major providers.

CI/CD

C DevOps

Continuous Integration and Continuous Deployment/Delivery. A set of practices that automate the processes of software development, testing, and deployment.

Keywords
Use Cases
  • Automated testing on every commit
  • Deploying to production on merge
Did you know?
  • Tools like Jenkins, GitHub Actions, and GitLab CI are standard.

Closure

C Scope

A feature where an inner function has access to the outer (enclosing) function's variables—a scope chain. The closure has three scope chains: it has access to its own scope, the outer function's variables, and the global variables.

Keywords
Use Cases
  • Data privacy / emulating private methods
  • Partial application / Currying
  • Event handlers maintaining state
Did you know?
  • Closures are created every time a function is created, at function creation time.

Columnar Storage

C OLAP

A database management system that stores data tables by column rather than by row. This is optimized for analytical queries (OLAP).

Keywords
Use Cases
  • Data Warehousing (BigQuery, Redshift)
  • Analytics
Did you know?
  • Allows for better compression and faster aggregation queries.

Compiled Language

C Performance

A programming language where the source code is translated into machine code by a compiler before execution, rather than being interpreted line-by-line at runtime.

Keywords
Use Cases
  • System programming (C, Rust, Go)
  • High-performance applications
Did you know?
  • Generally faster execution than interpreted languages.

Compliance

C Regulation

The practice of creating systems and processes to ensure that an organization adheres to laws, regulations, and industry standards.

Keywords
Use Cases
  • GDPR/CCPA for data privacy
  • HIPAA for healthcare
  • SOC2 audits
Did you know?
  • In IT, compliance often drives security architecture.

CompTIA

C Certification

Computing Technology Industry Association. A non-profit trade association that issues professional certifications for the information technology (IT) industry.

Keywords
Use Cases
  • Security+ certification
  • Network+ certification
Did you know?
  • Vendor-neutral certifications widely recognized in the industry.

Concurrency Mechanisms in IT

C Synchronization

Techniques used in operating systems and programming to manage the simultaneous execution of multiple processes or threads, ensuring data integrity and coordination.

Keywords
Use Cases
  • Mutexes and Semaphores
  • Monitors
  • Message Passing
Did you know?
  • Essential for preventing race conditions in multi-threaded applications.

Confusion Matrix

C Visualization

A table used to describe the performance of a classification model. It shows true positives, true negatives, false positives, and false negatives.

Keywords
Use Cases
  • Diagnosing specific types of errors a model is making
Did you know?
  • The basis for calculating Accuracy, Precision, Recall, etc.

Consensus Algorithms

C Distributed

Algorithms used to achieve agreement on a single data value among distributed processes or systems. Paxos and Raft are the most famous examples.

Keywords
Use Cases
  • Leader election
  • Distributed configuration (Etcd, ZooKeeper)
Did you know?
  • Essential for fault-tolerant distributed systems.

Consistent Hashing

C Distributed

A distributed hashing scheme that operates independently of the number of servers or objects in a distributed hash table by assigning them a position on an abstract circle, or hash ring.

Keywords
Use Cases
  • Distributing keys across shards
  • Load balancing
Did you know?
  • Minimizes reorganization when nodes are added or removed.

DAG

D Workflow

Directed Acyclic Graph. A finite directed graph with no directed cycles. It consists of vertices and edges, with each edge directed from one vertex to another, such that there is no way to start at any vertex v and follow a consistently-directed sequence of edges that eventually loops back to v.

Keywords
Use Cases
  • Airflow workflows
  • Spark execution plans
Did you know?
  • Used to model dependencies between tasks.

The World Wide Web content that exists on darknets, overlay networks that use the Internet but require specific software, configurations, or authorization to access.

Keywords
Use Cases

Did you know?

Data Lakehouse

D Architecture

A new, open data management architecture that combines the flexibility, cost-efficiency, and scale of data lakes with the data management and ACID transactions of data warehouses.

Keywords
Use Cases

Data Lineage

D Governance

The lifecycle that includes the data's origins and where it moves over time. It describes what happens to data as it passes through diverse processes.

Keywords
Use Cases

  • Compliance and auditing
Did you know?

Data Skew

D Performance

A condition where data is unevenly distributed across partitions in a distributed system. This leads to some tasks taking much longer than others (stragglers).

Keywords
Use Cases
  • A single key having 90% of the data in a join
Did you know?
  • Salting is a technique to mitigate skew.

DDoS

D Attack

Distributed Denial of Service. A malicious attempt to disrupt the normal traffic of a targeted server, service, or network by overwhelming the target or its surrounding infrastructure with a flood of Internet traffic from multiple sources.

Keywords
Use Cases
  • (Malicious) Taking down a competitor's website
  • Cyber warfare
Did you know?
  • Often utilizes botnets of compromised devices (IoT).

Deadlock

D Concurrency

A situation where a set of processes are blocked because each process is holding a resource and waiting for another resource acquired by some other process.

Keywords
Use Cases
  • Database transactions waiting on each other's locks
  • Multi-threaded applications
Did you know?
  • Can be prevented by resource ordering or timeout mechanisms.

Debentures

D Finance

A type of long-term business debt not secured by physical assets or collateral. It is backed only by the general creditworthiness and reputation of the issuer.

Keywords
Use Cases
  • Corporate fundraising
  • Government bonds
Did you know?
  • Holders are creditors, not owners.

Defer

D HTML parsing

In the context of HTML scripts, a boolean attribute indicating that the script should be executed after the document has been parsed. In Go, a statement that schedules a function call to be run after the function completes.

Keywords
Use Cases
  • Loading JavaScript without blocking HTML rendering
  • Ensuring resource cleanup (closing files/connections) in Go
Did you know?
  • Scripts with `defer` execute in order.
  • In Go, deferred calls are executed in LIFO order.

Design Patterns

D Architecture

General, reusable solutions to a commonly occurring problem within a given context in software design.

Keywords
Use Cases
  • Singleton (one instance)
  • Factory (creating objects)
  • Observer (event handling)
Did you know?
  • Popularized by the 'Gang of Four' book.

Dimensionality Reduction

D PCA

The process of reducing the number of random variables under consideration by obtaining a set of principal variables. It simplifies models and reduces computation time.

Keywords
Use Cases
  • Visualizing high-dimensional data
  • Removing noise
Did you know?
  • Principal Component Analysis (PCA) is a popular linear technique.

DNS

D Networking

Domain Name System. The phonebook of the Internet. It translates human-readable domain names (like google.com) to machine-readable IP addresses.

Keywords
Use Cases
  • Accessing websites
  • Email routing (MX records)
Did you know?
  • DNS propagation can take up to 48 hours.

Denial of Service. Similar to DDoS, but the attack originates from a single source.

Keywords
Use Cases

Did you know?

Doxing

D Privacy

The act of publicly revealing previously private personal information about an individual or organization, usually through the Internet. It is often used as a form of online harassment or vigilantism.

Keywords
Use Cases
  • Malicious exposure
  • Hacktivism
Did you know?

DRY

D Principle

Don't Repeat Yourself. A principle of software development aimed at reducing repetition of software patterns, replacing it with abstractions or using data normalization to avoid redundancy.

Keywords
Use Cases
  • Creating reusable functions
  • Using variables for constants
  • Inheritance in OOP
Did you know?
  • Formulated by Andy Hunt and Dave Thomas in 'The Pragmatic Programmer'.

Dynamic Programming

D Algorithm

A method for solving complex problems by breaking them down into simpler subproblems. It is applicable to problems exhibiting the properties of overlapping subproblems and optimal substructure.

Keywords
Use Cases
  • Fibonacci sequence
  • Shortest path problems
  • Knapsack problem
Did you know?
  • Uses memoization or tabulation to store results.

Dynamic Typing

D Type System

A type system where type checks are performed at runtime. Variables are not bound to a specific type and can hold value of any type during execution.

Keywords
Use Cases
  • Python
  • JavaScript
  • Ruby
Did you know?
  • Offers more flexibility but can lead to runtime type errors.

Edge Computing

A distributed computing paradigm that brings computation and data storage closer to the sources of data. This is expected to improve response times and save bandwidth.

Keywords
Use Cases
  • IoT devices processing data locally
  • Real-time analytics
Did you know?
  • Reduces the load on the central cloud.

Low-dimensional, continuous vector representations of discrete variables (like words or items). They capture semantic relationships where similar items are closer in the vector space.

Keywords
Use Cases
  • Word2Vec
  • Recommendation systems
  • Semantic search
Did you know?
  • Allow computers to understand the 'meaning' of words mathematically.

Keywords
Use Cases

ETL vs ELT

E Data Pipeline

ETL (Extract, Transform, Load) transforms data before loading it into the target system. ELT (Extract, Load, Transform) loads raw data first and then transforms it within the target system (typically a cloud data warehouse).

Keywords
Use Cases
  • ETL for legacy systems
  • ELT for modern cloud warehouses (BigQuery, Snowflake)
Did you know?
  • ELT leverages the processing power of the destination warehouse.

Event Loop

E Single-threaded

The mechanism that allows JavaScript to perform non-blocking I/O operations despite being single-threaded. It constantly checks if the call stack is empty and if the callback queue has pending tasks to process.

Keywords
Use Cases
  • Handling user interactions while fetching data
  • Timers (setTimeout)
Did you know?
  • The browser has an event loop, Node.js has an event loop (libuv).

A software architecture paradigm promoting the production, detection, consumption of, and reaction to events.

Keywords
Use Cases

Did you know?
  • Kafka and RabbitMQ are popular tools for this.

Exactly-Once Semantics

E Streaming

A guarantee in stream processing that each record will be processed exactly once, even in the event of failures. No data is lost, and no data is processed twice.

Keywords
Use Cases
  • Financial transactions
  • Accurate counting
Did you know?
  • Hardest to achieve; Kafka and Flink support it.

A geopolitical and strategic principle describing the severe tendency toward war when a rising power threatens to displace an established ruling hegemon, creating mutual paranoia and structural instability.

Keywords
Use Cases
  • Analyzing great-power rivalry and international relations (e.g., US-China strategic friction)
  • Modeling platform displacement when an insurgent technology challenges an incumbent market leader
  • Designing diplomatic de-escalation protocols and strategic guardrails to prevent accidental conflict
Did you know?
  • Coined from Thucydides' chronicle of the Peloponnesian War, a Harvard Belfer Center study found that in 16 historical instances over 500 years where an emerging power rivaled a ruling hegemon, 12 culminated in war.
